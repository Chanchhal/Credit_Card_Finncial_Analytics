This project focuses on analyzing credit card transaction and customer data using *Microsoft Power BI and SQL*.

The objective is to transform raw financial data into an interactive dashboard that provides insights into revenue, transaction trends, customer behavior, card usage, and overall financial performance.

The dashboard is designed to help business teams monitor key performance indicators and identify trends that can support data-driven decision-making.

---

## 🎯 Business Objectives

The project aims to answer the following business questions:

- What is the total revenue generated?
- How many transactions were processed?
- What is the total transaction amount?
- Which card categories generate the highest revenue?
- Which customer segments contribute the most revenue?
- Which states have the highest transaction activity?
- What are the monthly revenue and transaction trends?
- Which transaction types are most commonly used?
- How does customer spending vary across different demographics?
- How does credit card usage change over time?

---
